# features:
-  interactable dino icon to navigate page(its operational thru drag, scroll, spacebar and arrow keys).
-  horizontal scrolling for large screen(computer & laptops) and a simplified normal versiom for small screens.
-  navbar, navbar transitions, navbar links.
-  dino transitions, ground transitions(till the footer).
-  home page, with dropdown about section.
-  work page with past projects. 
-  a contact page with emailjs.
-  a 404 page with a builtin game ( we copied discord).
-  cursor trail, trail of pixels follow the cursor.
-  oh and super smooth scrolling and momentum with lenis.
-  a super cool footer.
-  themes, everything has a theme, everything, even the 404 page,
-  its all black and white.
